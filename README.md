# 宠物丑萌涂鸦 / Doggy Doodle

把真实宠物照片转换成一套风格统一、只保留轻度宠物提示的装饰涂鸦。

> **系列感优先 + 轻度宠物特征保留。**

目标不是宠物似颜绘，也不是通用低幼卡通。相似度主动控制在约 45%–60%：能看出参考了这只宠物，但画面首先属于同一个装饰插画系列。

## 统一系列规则

- 正方形卡片和可自由轮换的单色纸张背景；
- 粗钝黑色外轮廓，约为内部线条的 2–3 倍；
- 简单圆点眼、大图形鼻、弱化嘴巴；
- 稍大的头、毛茸茸块面身体和厚爪子，并保留原照片的大姿势；
- 蜡笔/马克笔式不均匀上色；
- 顶部、左右和底部由大小不一的英文手写字参与构图；
- 文字存在时只保留 2–5 个根据宠物特征变化的波纹、弧线或小符号。

## 背景颜色与周围元素

- 用户指定颜色时优先使用；未指定时从宝蓝、青绿、薄荷、珊瑚粉、奶油黄、暖白、灰紫和浅天蓝中自动选择；
- 选色优先让宠物毛色与背景拉开对比，并在一组图里轮换颜色；
- 背景始终是一块带轻微纸张颗粒的平涂色，不使用渐变、房间或地板场景；
- 垂耳会变成耳侧弧形波纹，立耳会变成短射线，胡子会变成断续波浪，蓬松身体会变成云朵弧线，围巾会变成斜线或小三角；
- 主装饰只提取一个宠物特征，再加最多一种爱心、星星或对话框。

## 文字环绕规则

- 默认使用一个顶部大标题、左右各 1–2 组短句，以及可选的一行底部小字；
- 文字约占背景面积的 25%–40%，把主体四周排得充实，但不压住狗狗；
- 每张使用 3–5 个英文短语、总计约 12–22 个单词，文字歪斜、大小不同并带马克笔手感；
- 深色背景自动使用暖白、奶油色或浅黄色文字；
- 浅色背景自动使用黑色、深蓝或深灰文字；
- 用户提供英文时逐字使用；未提供时从 `HAPPY`、`GOOD DOGGY`、`ONLY YOU`、`SO FLUFFY`、`LOVE YOU`、`CUTEST`、`MY BEST GIFT` 等短句中选择；
- 出现拼写错误或乱码时必须减少短句后重试。

## 可控凌乱度

在稳定构图上增加约 15%–20% 的凌乱：

- 5–8 处局部重复描线或补线；
- 2–4 处轻微断线、开口或出头；
- 3–6 处漏涂、深浅不均或颜色轻微越界；
- 少量耳朵、胡子、肩膀和爪子附近的短碎线。

脸、鼻子和整体轮廓仍然必须清楚。目标是“画的时候随手补了几笔”，不是幼儿式满画面乱涂。

## 宠物只保留 2–4 个提示

- 毛色或主要色块；
- 耳朵类型；
- 大概脸型或身材倾向；
- 最多一个胡子、眉毛、白斑或高低耳特点。

不再保留真实眼神、精确五官位置、复杂表情、毛发走向、真实站姿和细碎斑纹。

## 姿势跟随原照片

- 照片坐着就画坐着，站着就画站着；
- 奔跑、跳跃、趴着、躺着、蜷睡、回头、探头或抬爪都会保留对应的大动作；
- 姿势不占用 2–4 个外貌提示名额；
- 只保留动作轮廓、身体方向和一个关键动作点，不追求真实关节和解剖；
- 禁止把所有宠物套成坐姿，也禁止给静止照片擅自增加奔跑动作。

## 输出模式

- **有文字版：** 英文手写字环绕 + 2–5 个小装饰；
- **无文字版：** 完全没有字，只使用 4–8 个宠物特征响应式线条或符号；
- **双版本：** 先生成无文字动作母版，再基于同一只狗、同一姿势和同一配色制作文字版。

## 安装

```bash
mkdir -p ~/.codex/skills
cp -R doggy-doodle ~/.codex/skills/doggy-doodle
```

重新开启一个 Codex 任务后使用：

```text
使用 $doggy-doodle，把这只宠物画成系列感优先、轻度相似的狗狗乱画。
```

## 中间版检查

最终必须同时满足：

1. 系列感统一；
2. 保留 2–4 个宠物提示；
3. 不像真实宠物肖像；
4. 不像通用卡通狗；
5. 首先是一张系列装饰画，其次才让人想到参考宠物。

## 公开名称与简介

**名称：** 宠物丑萌涂鸦 / Doggy Doodle

**简介：** 上传宠物照片，统一转换成粗描边、豆豆眼、可变色背景和英文手写字环绕的系列涂鸦；文字会随背景明暗自动反色，并从宠物特征提取少量波纹线条。
